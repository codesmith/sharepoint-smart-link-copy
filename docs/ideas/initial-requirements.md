# Smart Link Copy（smart-sharepoint-link）- アイデアメモ

## このドキュメントの位置づけ

このドキュメントは壁打ち・ブレストの成果物で、正式な仕様書ではありません。

## プロダクトビジョン

SharePoint / OneDrive上のファイル・フォルダーを右クリックひとつで、
フォルダー階層がひと目でわかる「パンくずリンク付きテキスト」としてコピーできるChrome拡張機能。

**一言で言うと**: SharePointのファイル/フォルダーリンクを、パンくず形式のリッチテキストリンクに変換してコピーする拡張機能

---

## 解決したい課題

SharePointのファイルリンクやフォルダーリンクをコピーすると、Teamsやメールに貼り付けた際に
「ファイル名のみ」「フォルダー名のみ」しか表示されず、そのファイル/フォルダーがどの階層にあるのか
貼り付け先だけでは分からない。

---

## ターゲットユーザー

社内の同僚・チーム全体。SharePoint/OneDriveで資料を共有する際に、
共有相手が場所を把握しやすいようにするのが目的。

---

## 主要機能（MVP）

### Smart Link Copy

#### 動作イメージ

1. SharePoint/OneDriveのページ上で、ファイルまたはフォルダーを**単一選択**して右クリックする
2. コンテキストメニューに **「Smart Link Copy」** が追加表示される
3. クリックすると、パンくず形式のリッチテキスト（HTML clipboard）がコピーされる
4. Teams / OneNote に貼り付けると、以下のようにパンくずリンクとして表示される

sample1(フォルダーパスコピー時)
```
# 階層
マイファイル > ■勉強会資料 > _old

# 元となるOneDriveリンク(ブラウザのURLバーの値をコピー)
https://onedrive.live.com/my?id=%2Fpersonal%2F00d5c5517f1d115b%2FDocuments%2F%E2%96%A0%E5%8B%89%E5%BC%B7%E4%BC%9A%E8%B3%87%E6%96%99%2F%5Fold&viewid=2a6deb66%2D3a2f%2D4309%2Db04f%2Dd0cc7d8819f7
```

sample2(ファイルパスコピー時)
```
# 階層
マイファイル > ■勉強会資料 > _old > 20260502_01Playwrightハンズオン_Playwright勉強会資料.pptx

# 元となるOneDriveリンク(ファイル選択後、コンテキストメニューから「リンクのコピー」を選択)
https://1drv.ms/p/c/00d5c5517f1d115b/IQDCtXY9HkNgQ4GEOYZ1ArkHATEu3O_vMhZ6G9-Y-XswOxM?e=hUtgcB
# 上記URLはSharePointの機能により作られた短縮URLのため、Chromeに表示されている情報からは階層情報を取得できないと思われる。そのため、このChrome拡張機能ではsample1のように
ブラウザのURLバーからの情報をインプットにしてフォルダー階層部分は親フォルダー、子フォルダー、孫フォルダー、…全てリンクを構築し、ファイルのみはリンク化しない。
```

#### フォーマット仕様

- 区切り文字: 各リンクの間に「半角スペース」+「>」+「半角スペース」（` > `）を挿入する
- ファイルをコピーした場合: トップフォルダーから対象ファイルまでの全階層 + ファイル名を表示
  - 例: `【親フォルダー】 > 【子フォルダー】 > 【孫フォルダー】 > 【ファイル名】`
- フォルダーをコピーした場合: トップフォルダーから対象フォルダーまでの全階層を表示（対象フォルダー自身が末尾）
- 起点セグメント（後述の「トップフォルダー」名）自体はリンクなしのプレーンテキストとする
- 起点以外の各セグメント（親・子・孫フォルダー、およびファイル/フォルダー本体）はそれぞれ個別にハイパーリンクを持つ
  - リンク先は各階層の実際のフォルダー（クリックするとそのフォルダーに遷移できる）
  - 上記の通り、ファイル名部分はリンク化が困難のため、初回実装時はスコープ外としてよい。

#### 「トップフォルダー」の定義

- OneDrive（個人）の場合: 「マイファイル」を起点とする
- SharePointチームサイトの場合: ドキュメントライブラリ名（例: `Documents`）を起点とする

#### 対応する貼り付け先（MVP）

- Microsoft Teams
- OneNote

（HTML clipboard形式でのリッチテキスト貼り付けを前提とする）

#### MVP対象外・非考慮事項

- 複数ファイル/フォルダーを同時選択して右クリックした場合の挙動（今回は単一選択時のみメニューを表示する）
- プレーンテキストしか受け付けない貼り付け先（メモ帳等）でのフォールバック表示（今回は考慮しない）
- Smart Link Copy以外の機能（今回はこの1機能に集中する）
- ファイル名部分はリンク化しなくて良い。

## 技術的な検討事項

### 認証

- Microsoft 365 / Graph APIなどの認証・API連携は**不要**
- ブラウザ上のDOM操作・URL操作のみで完結させる方針

### 動作範囲

- SharePoint / OneDriveのWebページ上のみで動作する（他サイトでは動作しない）

### 各階層リンクのURL取得方法

- パンくずの各階層（親・子・孫フォルダー）は、実際にそのフォルダーへ遷移できる実リンクを付与する
- SharePoint/OneDriveページ上のパンくずナビゲーションやフォルダー階層情報からDOM経由でURLを取得することを想定（詳細な取得方法は設計フェーズで検討）

### クリップボード操作

- リッチテキスト（HTML）としてクリップボードに書き込む必要がある（Clipboard API / `text/html` MIMEタイプ）
- Manifest V3のChrome拡張機能として実装する想定
- コンテキストメニューは `chrome.contextMenus` APIを使用し、対象がファイル/フォルダー単一選択時のみ表示する
