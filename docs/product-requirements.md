# プロダクト要求定義書 (Product Requirements Document)

## プロダクト概要

### 名称
**Smart Link Copy**(リポジトリ名: `smart-link-copy`) - SharePoint/OneDriveのフォルダー階層や、Backlogの課題の文脈が一目でわかるリンクコピー拡張機能

### プロダクトコンセプト
- **階層が見えるリンク**: 現在見ているフォルダーへのリンクを、トップフォルダーからの全階層をたどれるパンくず形式でコピーする
- **右クリックひとつで完結**: 対象のフォルダーを開いた状態で右クリックし、コンテキストメニューから選択するだけで使える
- **認証・API連携なしで完結**: Microsoft 365やGraph APIとの連携を行わず、ブラウザ上のURL操作のみで実現する

### プロダクトビジョン
SharePoint/OneDriveでフォルダーを共有する際、リンク先のテキストが「フォルダー名のみ」になってしまい、
共有された相手はそのフォルダーがどこにあるのか分からない、という問題を解消する。
Smart Link Copyは、コンテキストメニューに「Smart Link Copy」を追加し、**現在開いているフォルダー**の
階層をパンくず形式のリッチテキストリンクとしてコピーできるようにする。
Teams/OneNoteに貼り付けるだけで、共有相手は場所を直感的に把握でき、各階層のリンクからも該当フォルダーへ直接アクセスできる。

> **MVPのスコープ**: 当初はファイル/フォルダーの行を右クリックして個別に対象を指定する方式を検討したが、
> SharePoint/OneDriveはファイル/フォルダー行の右クリックに対して独自のコンテキストメニューを表示し、
> ブラウザ標準のコンテキストメニュー(拡張機能のメニュー項目を含む)を抑制してしまうため、拡張機能側では
> 個別の行を対象にすることができないことが実機検証で判明した。そのため、MVPでは「右クリックした対象」ではなく
> 「**現在アドレスバーに表示されているフォルダーの位置**」を常にコピーする方式に変更した(詳細は`docs/functional-design.md`参照)。
> 加えて、ファイルの共有ニーズに応えるため、右クリックした対象ではなく「**選択されているアイテム**」(選択状態は
> 独自コンテキストメニューの影響を受けない)の名前を、パンくずの下に列挙してコピーする機能を追加した。
>
> **対応サービスの拡大**: Backlogの課題URLも同様に「URLだけでは何の課題か分からない」問題があるため、
> Backlogの課題ページでも「Smart Link Copy」で「プロジェクト名 > 課題名」と課題URLをコピーできるようにした。
> これに伴い、プロジェクト名(リポジトリ名)を`smart-sharepoint-link`から`smart-link-copy`に変更した。

### 目的
- SharePoint/OneDriveのリンク共有時に発生する「場所が分からない」問題を解消する
- 社内のファイル共有コミュニケーションの手戻り(「どこのフォルダ？」という質問のやり取り)を削減する
- フォルダーを開いて右クリックするだけで使える、学習コストの低い機能を提供する

## ターゲットユーザー

### プライマリーペルソナ: 社内エンジニア/バックオフィス社員(業種・年齢不問)
- 日常的にSharePoint/OneDriveで資料を保存・共有している
- Teams・OneNoteを使って社内コミュニケーションを行っている
- フォルダーを共有するたびに、階層情報を手動でメッセージに書き足す、または「どこのフォルダですか？」と聞かれることがある
- **現在の課題**: SharePointの「リンクのコピー」機能でコピーしたリンクをTeams等に貼り付けても、フォルダー名しか表示されず、共有相手が場所を把握できない
- **期待する解決策**: 共有したいフォルダーを開いた状態で右クリックするだけで、階層情報付きのリンクを共有できるようになること
- **典型的なワークフロー**: SharePoint/OneDriveで共有したいフォルダーを開く → ページ内で右クリックして「Smart Link Copy」を選択 → Teamsのチャットやチャネル、OneNoteに貼り付けて共有する

- 「どこのフォルダですか？」という確認のやり取りの体感的な減少: 配布後1ヶ月時点でのアンケートで「減った」と回答した割合60%以上
- 拡張機能利用時のエラー発生報告件数: 月1件以下

## 機能要件

### コア機能(MVP)

#### Smart Link Copy(現在地のパンくずリンクコピー機能)

**ユーザーストーリー**:
社内でSharePoint/OneDriveのフォルダーを共有する社員として、共有相手がフォルダーの場所を直感的に把握できるようにするために、
共有したいフォルダーを開いて右クリックするだけで、そのフォルダーの階層付きリンクをコピーできる機能が欲しい

**受け入れ条件**:
- [x] SharePoint/OneDriveのドキュメントページ上で右クリックすると、コンテキストメニューに「Smart Link Copy」が表示される
      (SharePoint/OneDrive自身が独自のコンテキストメニューを表示する場所では、ブラウザ標準メニューごと
      抑制されるため表示されないことがある。これは拡張機能側では制御できない既知の制約)
- [x] 「Smart Link Copy」をクリックすると、クリップボードにリッチテキスト(HTML clipboard形式)として、
      **右クリックした場所に関わらず、現在アドレスバーに表示されているフォルダー**のパンくずリンクがコピーされる
- [x] コピーされる内容は、区切り文字` > `(半角スペース+`>`+半角スペース)で連結された階層テキストである
- [x] 起点(トップフォルダー)から現在表示しているフォルダーまでの全階層が表示され、現在のフォルダー自身が末尾となる
- [x] 起点セグメントはリンクなしのプレーンテキストとして表示される
- [x] 起点以外の各フォルダーセグメント(現在のフォルダー自身を含む)は、それぞれ実際にそのフォルダーへ遷移できるハイパーリンクを持つ
- [x] OneDrive(個人)の場合、起点は「マイファイル」となる
- [ ] SharePointチームサイトの場合、起点はページヘッダーに表示されているサイト名となる
      (同じライブラリ名(例:「Shared Documents」)が複数サイトで重複し、どのサイトの資料か分からなくなるため。
      サイト名はURLから取得できずDOM読み取りに依存するため、取得できない場合はドキュメントライブラリ名に
      フォールバックする)
- [x] フォルダー階層のリンク構築は、ブラウザの現在のアドレスバーURL(フォルダーパス情報を含むクエリパラメータ)を情報源として行う
- [ ] Microsoft Teams、OneNoteに貼り付けた際に、意図通りの階層テキストとリンクが表示される(実機での最終確認待ち)

**優先度**: P0(必須)

#### 選択アイテム一覧付きコピー

**ユーザーストーリー**:
特定のファイルを共有したい社員として、「どのフォルダーの、どのファイルか」を1回のコピー&ペーストで伝えるために、
ファイルを選択した状態で「Smart Link Copy」を実行すると、パンくずの下に選択したファイル名も続けてコピーされる機能が欲しい

**ペースト時のフォーマット**(`　`は全角スペース(U+3000)):

```
マイファイル > ◆自己紹介 > 20250108_トリセツ
　┗ 20231122_近況報告_DED_山田太郎.pptx
　┗ Cropped_Image.png
```

**受け入れ条件**:
- [ ] 1つ以上のアイテムが選択された状態で「Smart Link Copy」を実行すると、1行目に現在のフォルダーのパンくず、
      2行目以降に選択アイテム名が「`　┗ `」(全角スペース + `┗` + 半角スペース)を行頭に付けて1アイテム1行で出力される
- [ ] 選択アイテム名はリンクを持たないプレーンテキストで、HTML特殊文字はエスケープされる
      (ファイルの実リンクはURLから構築できないため)
- [ ] アイテムの並び順は画面上の表示順である
- [ ] 選択アイテムが0件の場合は、従来通りパンくずのみが出力される(余分な改行を付けない)
- [ ] 右クリック操作によってSharePoint/OneDrive側で選択が解除される場合でも、右クリック直前の選択状態が反映される
- [ ] 選択アイテム名を取得できない場合(DOM構造が想定外の場合)でも、パンくずのコピーは従来通り成功する
- [ ] Microsoft Teams、OneNoteに貼り付けた際に、行(改行)と行頭の`　┗`が維持される(実機での最終確認待ち)

**優先度**: P0(必須)

#### Backlog課題リンクコピー

**ユーザーストーリー**:
Backlogの課題をTeams等で共有する社員として、共有相手が「どのプロジェクトの何の課題か」をリンクを開かずに把握できるようにするために、
課題ページで右クリックするだけで、プロジェクト名・課題名付きの課題リンクをコピーできる機能が欲しい

**ペースト時のフォーマット**:

```
Spring開発標準 > 【アプリケーション方式設計書_1はじめに.xlsx】1.1 本書の目的
https://yonespring.backlog.com/view/SPRING-3
```

| 項目 | 取得元 |
|------|--------|
| プロジェクト名 | ページ上部のプロジェクト名表示(`<span class="header-icon-set__name">`) |
| 課題名 | 課題の件名欄(`[data-testid="issueSummary"]`内の`<div class="markdown-body">`) |
| 課題URL | ブラウザのアドレスバーURL(`https://<スペース>.backlog.com/view/<課題キー>`。クエリ・ハッシュは除去) |

**受け入れ条件**:
- [ ] Backlogの課題詳細ページ(`/view/<課題キー>`)で右クリックすると、コンテキストメニューに「Smart Link Copy」が表示される
- [x] 1行目に「プロジェクト名 > 課題名」、2行目に課題URLがコピーされる
- [x] HTML形式では課題URLがハイパーリンクになり、プロジェクト名・課題名・URLはHTMLエスケープされる
- [x] プロジェクト名を取得できない場合は、URLのプロジェクトキー(例: `SPRING`)で代替する
- [x] 課題名を取得できない場合は、エラーを通知しクリップボードを上書きしない
- [ ] Microsoft Teams、OneNoteに貼り付けた際に、2行で表示され、URLがリンクになる(実機での最終確認待ち)

**優先度**: P0(必須)

### 拡張機能の操作フロー

```
1. SharePoint/OneDriveで、共有したいフォルダーを開く(そのフォルダーの中に入る)
2. (特定のファイルも伝えたい場合)共有したいファイルを選択する(複数選択可)
3. ページ内で右クリックする(ファイル/フォルダー行以外の場所を推奨。行の上はMicrosoft独自メニューに
   奪われることがあるため)
4. コンテキストメニューから「Smart Link Copy」を選択する
5. Teams または OneNote の入力欄に貼り付ける(Ctrl+V)
   → 現在開いているフォルダーのパンくず形式のリンク付きテキストが挿入される
   → ファイルを選択していた場合は、パンくずの下に「　┗ ファイル名」が1行ずつ続く
```

Backlogの場合:

```
1. Backlogで共有したい課題の詳細ページを開く
2. ページ内で右クリックし、コンテキストメニューから「Smart Link Copy」を選択する
3. Teams または OneNote の入力欄に貼り付ける(Ctrl+V)
   → 「プロジェクト名 > 課題名」と課題URL(リンク付き)の2行が挿入される
```

### 将来的な機能(Post-MVP)

#### サイト名自体へのリンク付与

起点セグメント(SharePointサイト名)に、そのサイトのトップページへの実リンクを付与する。
サイトのトップページURLを特定できる手段が見つかった場合に検討する。

**優先度**: P2(できれば)

#### 選択アイテム自体へのリンク付与

「選択アイテム一覧付きコピー」で出力するアイテム名(現在はリンクなしのテキスト)に、そのファイル/フォルダー自体への
実リンクを付与する。SharePoint/OneDriveのファイルリンクは短縮URLで、アドレスバーのURLからは構築できないため、
ファイルをプレビュー表示した際のURL形式の調査など、リンクを取得できる手段が見つかった場合に検討する。

**優先度**: P1(重要)

#### 複数選択時の一括コピー対応

複数のフォルダーを同時に扱いたい場合に、各フォルダー分のパンくずを改行で並べてコピーできるようにする。

**優先度**: P2(できれば)

#### プレーンテキストのみ対応の貼り付け先へのフォールバック

メモ帳等、リッチテキスト(HTML clipboard)を受け付けない貼り付け先向けに、リンクなしのパンくずテキストを併せて用意する。

**優先度**: P2(できれば)

#### 対応貼り付け先の拡大

Outlookのメール作成画面やWordなど、Teams/OneNote以外のリッチテキスト対応アプリへの対応範囲拡大を検討する。

**優先度**: P1(重要)

## 非機能要件

### パフォーマンス
- コンテキストメニューからのコピー実行: クリックからクリップボード書き込み完了まで500ms以内

### ユーザビリティ
- 既存のSharePoint/OneDriveの「リンクのコピー」操作と同じ場所(右クリックメニュー)に機能を追加し、新たな操作方法を覚える必要がない
- 初めて使う社員でも、説明を受けずにメニュー名(「Smart Link Copy」)から機能の意図を理解できる

### 信頼性
- コピー内容が意図した階層・リンクと異なる場合(パンくず構築に失敗した場合)は、エラーを通知しクリップボードを上書きしない

### セキュリティ
- Microsoft 365アカウントの認証情報やアクセストークンを一切扱わない(OAuth/Graph API連携を行わない)
- BacklogのAPIキー・認証情報も扱わない(Backlog API連携を行わず、表示中のページのDOM/URLのみを読む)
- 拡張機能が収集・送信する個人情報・業務データは無い(すべてブラウザのローカル処理で完結する)

### スケーラビリティ
- フォルダー階層の深さに上限を設けず、何階層でもパンくずを構築できること(実運用上想定される階層数、目安10階層程度までは動作を保証する)

## スコープ外

明示的にスコープ外とする項目:
- Microsoft 365 / Graph APIなど、認証を伴うAPI連携
- SharePoint/OneDrive・Backlog以外のWebページでの動作
- Backlogの課題詳細ページ以外(課題一覧・Wiki・ファイル等)でのコピー
- Backlog API連携(APIキー等の認証を伴う連携)
- Google Chrome以外のブラウザへの対応
- 選択アイテム自体へのリンク付与(Post-MVPで検討。ファイル名はリンクなしのテキストとして列挙する)
- 右クリックした特定のファイル/フォルダー行を対象として個別に指定する仕組み(行のコンテキストメニューは
  SharePoint/OneDrive側に制御されており拡張機能側では介入できないため、「現在地」+「選択状態」ベースの方式とした)
- 選択アイテムがファイルかフォルダーかの区別表示(選択されたものを同じ形式で列挙する)
- リスト表示以外のビュー(写真ビュー・タイル表示等)での選択検知
- プレーンテキストのみ対応の貼り付け先(メモ帳等)へのフォールバック(Post-MVPで検討)
- Teams/OneNote以外のアプリへの貼り付け対応(Post-MVPで検討)
- Chrome Web Storeでの一般公開(社内限定配布のみを対象とする)
